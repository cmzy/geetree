# Screenshots

Full-size screenshots of GeeTree, a folder per version, a folder per colour theme,
dark and light in each:

```
0.5.0/
  geetree/{dark,light}/   the default theme
  classic/{dark,light}/   Classic
  nord/{dark,light}/      Nord
```

Each folder holds the same 50 pages under the same names. PNG, window only,
2880 × 1802 (a 1440 × 901 window at 2x); the compare window is 2720 × 1722 and
the file compare window 2560 × 1642. The repository in them is the Linux kernel
(1,505,188 commits); the interface is in English.
